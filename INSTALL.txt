HUD Resize & 4:3 / 5:4 Fix (Deadlock)
=====================================
A complete, un-stretched HUD on 4:3, 5:4 and other narrow screens, and a HUD size of your choice on
any screen. Only the interface changes. Each zip is one HUD size: size1.0 is the plain fix (on 16:9
and 16:10 it changes nothing), 0.5 ... 0.9 are smaller, 1.1 ... 1.5 larger. Install exactly one.

With Deadlock Mod Manager: install from the GameBanana page and pick one size.

Manually:
1. Open Deadlock/game/citadel/ (Steam > Deadlock > Manage > Browse local files > game/citadel).
2. Create a folder named "addons" there if it does not exist and copy pak01_dir.vpk into it.
   (If a pak01_dir.vpk from another mod is already there, rename this one to the next free
   number: pak02_dir.vpk, pak03_dir.vpk, ...)
3. Open gameinfo.gi in a text editor. Inside FileSystem > SearchPaths, make the first lines read:

            Mod                 citadel
            Write               citadel
            Game                citadel/addons
            Game                citadel
            Game                core

   Deadlock updates overwrite this file; add the lines again when the mod stops loading.
4. Narrow screens only: set your resolution in Steam > Deadlock > Properties > Launch Options,
   e.g.  -w 1280 -h 1024   (the game's video settings only list 16:9, 16:10 and 21:9 modes).
5. Restart Deadlock.

Uninstall: delete the vpk from the addons folder.

Source, issues and all sizes: https://github.com/Vergir/deadlock-hud-resize
